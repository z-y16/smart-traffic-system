# ── Emergency vehicle detection ───────────────────────────────────────────
# What raises emergency mode is the *siren light* (siren_vision.py), and that
# needs nothing beyond OpenCV and NumPy — no weights, no download, no GPU. The
# packages below are only for recognising the vehicle's livery, which names the
# type when a red beacon could be an ambulance or a fire engine.
#
# CLIP identifies ambulances, police cars and fire trucks with no training and
# no dataset, which is why it is the default. Ultralytics installs it
# automatically the first time it is needed; install it up front to avoid a
# mid-run download:
clip @ git+https://github.com/ultralytics/CLIP.git
# The ViT-B/16 weight file (~335 MB) downloads on first use and is cached.
# Without this package the system still runs and still detects sirens; what is
# lost is telling an ambulance from a fire engine (--no-emergency-ai makes that
# explicit).

# ── Training your own livery model (train_emergency_classifier.py, optional) ─
# Only needed to *build* emergency_cls.pt; running it needs nothing extra.
# pandas reads the Hugging Face parquet files the training images come in.
pandas>=2.0.0

# such a link is refused with a message saying so; everything else still works:
